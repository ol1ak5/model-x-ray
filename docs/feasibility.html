Terminology

Watermarking vs fingerprinting

Anthropic announced a text watermark for Claude in summer 2026. It is a statistical pattern added while the model writes, and it answers one question: did Claude write this? Google's SynthID Text works the same way. We need something different: every recipient gets a slightly different copy of an existing document, and a leaked fragment points back to one copy. The literature calls this fingerprinting or traitor tracing, and the intelligence world calls it a canary trap.

1

Parse and lock

Split the document into sentences with stable IDs. Lock every number, currency amount, percentage, date, company or person name, and quoted defined term ("the Target", "Closing Date"). Rules plus a Nemotron Nano pass. Contracts and financial statements are excluded entirely; only narrative documents (info memo, teaser, management presentation text, board pack commentary) are marked.

2

Find swap points

Nemotron Super returns structured JSON for each sentence: 2–3 swap points, each with 2–3 equivalent variants. Types: synonym, connective ("and" / "as well as"), list order, clause order, active or passive voice, number format ("USD 40m" / "$40 million", value unchanged). Structural swaps survive paraphrase better than single words.

3

Verify meaning

Every variant must pass: locked spans identical character for character; a second model (Nemotron Nano) confirms both directions mean the same thing; a similarity score above a threshold. Anything doubtful is dropped. Optional one-time human review of the codebook in the UI.

4

Assign codewords

Each recipient's choice at each swap point comes from a keyed hash: HMAC(document_key, recipient_id, slot_id) mod k. Codewords look random, cannot be guessed without the key, and can be recomputed at any time. The registry stores who received which document version and when.

5

Render the copy

Apply that recipient's variants and export a PDF or DOCX that looks identical in layout. Optional second layer: zero-width characters carrying the ID with error correction, for instant matches on copy-pasted text. Optional visible footer "Prepared for [name]" as a deterrent.

6

Ingest the leak

Paste text, give a URL, or upload a screenshot or photo (read by Nemotron Nano Omni). Align each leaked sentence to its master sentence by similarity. A Tavily monitor can search news and the web for distinctive phrases from the documents and feed hits in automatically.

7

Read the variants

For each aligned swap point, decide which variant appears: exact match first, then model-assisted matching for paraphrased text. If it is unclear, mark the slot as unreadable rather than guess.

8

Score and report

For every recipient, add up the evidence: how many readable slots match their codeword, versus what chance would give. Report the top suspect with a confidence figure and the slot-by-slot evidence. If confidence is below a strict threshold, the system abstains. A false accusation in a deal is worse than no answer.

How many swap points a leak needs

Chance that an innocent recipient matches every readable slot by luck, with 200 recipients. This assumes clean matches; paraphrase lowers the readable count, which is exactly what the benchmark measures.

Readable slots in leakRoughly2 variants per slot3 variants per slot
103–5 sentences≈ 20% (abstain)≈ 0.3%
155–7 sentences≈ 0.6%≈ 0.001%
207–10 sentences≈ 0.02%negligible

Formula: N × k−L (N recipients, k variants, L slots). A 40-page info memo has hundreds of sentences, so capacity is not the bottleneck.

Code sketch

import hmac, hashlib, json, os
from openai import OpenAI

client = OpenAI(base_url="https://api.tokenfactory.us-central1.nebius.com/v1/",
                api_key=os.environ["NEBIUS_API_KEY"])

def find_swap_points(sentence: str, locked: list[str]) -> dict:
    prompt = ("Return JSON with 'slots': each has 'span' and 2-3 'variants' that mean exactly the same. "
              f"Never change these spans: {locked}. Sentence: {sentence}")
    r = client.chat.completions.create(
        model="nvidia/nemotron-3-super-120b-a12b",
        messages=[{"role": "user", "content": prompt}],
        response_format={"type": "json_object"})
    return json.loads(r.choices[0].message.content)

def choice(doc_key: bytes, recipient_id: str, slot_id: str, k: int) -> int:
    digest = hmac.new(doc_key, f"{recipient_id}:{slot_id}".encode(), hashlib.sha256).digest()
    return int.from_bytes(digest[:4], "big") % k

def score(observed: dict[str, int], recipients: list[str], doc_key: bytes, k: dict[str, int]):
    # observed: slot_id -> variant seen in the leak (unreadable slots omitted)
    results = []
    for rid in recipients:
        hits = sum(choice(doc_key, rid, s, k[s]) == v for s, v in observed.items())
        results.append((rid, hits, len(observed)))
    return sorted(results, key=lambda x: -x[1])

Real scoring will use a likelihood ratio with an error rate per slot type, so one misread slot does not clear the guilty copy.

Honest limits
  • Facts passed on verbally ("Company X is for sale") carry no wording. Access logs can only narrow the suspects.
  • Heavy paraphrase erases word-level marks. Structural marks (order, voice, clause order) hold up better; the benchmark will show where it breaks.
  • Bidders who compare copies can spot differences. Collusion-resistant codes (Tardos) need far more slots: workable for whole documents, not for a short quote. Stretch goal.
  • Marking must be disclosed in the NDA. That is normal practice and adds deterrence.
Benchmark

What we measure (the "numbers" judges reward)

  1. Generate a fictional 40-page info memo ("Project Falcon") with Nemotron and issue copies to 200 synthetic recipients.
  2. Leak fragments of 1, 3, 5 and 10 sentences.
  3. Attack each fragment: typos and retyping, screenshot and OCR, Nemotron paraphrase at light, medium and heavy strength, two bidders mixing their copies.
  4. Report top-1 accuracy, false-accusation rate (target: near zero, with abstention), and text quality (meaning preserved, judged blind).

The output is one chart: identification accuracy against fragment length, one line per attack. That chart is the centre of the video.

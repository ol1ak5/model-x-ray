# Benchmark

The benchmark is the project's conclusion: accuracy numbers quoted in the README, Devpost text and video. Design: `docs/evaluation.md` (authoritative); issues #12 (dataset), #16 (evaluators/runner), #17 (report).

## The core idea

One **clean base model** + seeded planted-error copies ⇒ exact ground truth. A fix is correct when the corrected copy's outputs match the clean base — **checked by recalculation, never by an LLM judge**.

## Dataset sets (default X = 25, configurable → 150 investigations)

| Set | What | Tests |
|---|---|---|
| types 1–4 | one error each: typed value / bad ref / skipped range / sign-period | detection per type |
| blended | 2–3 mixed, incl. symptom ≠ cause | root cause under noise, retry loop |
| overrides | documented deliberate hardcodes | **false-alarm rate** |
| clean | untouched | must report nothing wrong |

Seeded generation ⇒ reproducible. Ground truth JSON next to each variant: planted cells, error types, original formulas, expected outputs. Questions from templates targeting a line *downstream* of the planted error.

## Non-negotiable statistical rules

- Report **95% Wilson intervals**, never bare percentages (25 cases ⇒ ±10–20 points of uncertainty).
- Results **per set**, always. The four-way comparison (rules-only / Nano / Super / Super-without-tools) must not be rigged: rules are expected to win single clean errors; Nemotron earns its place on overrides (fewer false alarms) and blended cases. State the headline in those terms with the measured numbers.
- `verify` must be fed deliberately wrong patches so rejection ability is *measured*.

## Per-step metrics (each node its own metric)

`load_sheet` edge precision/recall · `map_model` label accuracy · `locate` exact match + clarification P/R · `trace` planted-cell recall (expect 100%) · `diagnose` top-1/top-3, error-type accuracy, false alarms, tool calls of budget 8 · `test` sandbox success + value match · `verify` verdict P/R on right *and* wrong patches · `explain` every cited cell exists and quoted number matches.

End-to-end: root-cause accuracy, fix accuracy, false-alarm rate, inconclusive rate, attempts, latency p50/p95, cost.

## Running

```sh
scripts/benchmark.sh        # zero flags — runs full set, writes docs/benchmark.md
```

The wrapper must take no arguments (AGENTS.md scripts rule); knobs live inside it as curated flags to `uv run tools/benchmark.py ...`. Full run is opt-in (calls Token Factory + Google APIs); evaluator tests use fixed fake outputs.

## Report (`docs/benchmark.md`, generated by the runner)

1. Results table per set (root-cause, fix accuracy, false alarms, p50/p95, cost)
2. Per-step table
3. Confusion matrix of predicted vs planted error types
4. Four-way comparison per set
5. Plain-language conclusion with intervals — quotable verbatim

Re-run and refresh numbers after **any** prompt or model change before submission (#17).
